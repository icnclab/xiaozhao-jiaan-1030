# 展示操作腳本（本機、模擬 LINE）

> 全部資料為合成；機構「幸福園」「松柏居」為虛構。展示前請確認畫面頂端的模式列：`line=mock` 代表 LINE 未真實串接。

## 0. 啟動（約 2 分鐘）

1. `docker compose up -d db`（WSL）。
2. `cd backend && uv run alembic upgrade head && uv run python scripts/seed_demo.py --reset`（重建合成資料；帳號密碼在 `F:\appdata\ltc_care\demo_accounts.txt`）。
3. 三個視窗：`uv run uvicorn app.main:app --port 8140 --reload`、`uv run python -m app.worker`、STT sidecar（`--model medium`）。Ollama 已 `serve` 且 `gemma4:e4b` 已 pull。
4. `cd frontend && npm run dev` → 瀏覽器開 `http://localhost:5173/liff`（手機尺寸）與 `http://localhost:5173/admin`。

## 1. 文字提問 → 附出處回答（A1）

- LIFF 首頁選「示範照服員 A1」→「問 AI」→ 輸入：`小照你好，302 王先生的家屬要我幫忙代購成藥，機構規定可以嗎？`
- 看點：問題被遮罩成「〔房號〕〔個案〕…」；「已辨識喚醒詞」標籤；兩句主張各附出處（營運規範第 5 條第 2 版＋幸福園內規）；「查看原文」回到該版本條文與前後文；「AI 初步參考」標示。
- 按「播放語音」：SAPI 產生 m4a，`<audio>` 可播；播放 URL 為限時簽章。

## 2. 版本差異（A11）

- 問：`夜間每多少位住民要配置一名照服員？` → 引「第 2 版」（每二十位）；第 1 版（每二十五位，已失效）不會出現。
- 後台「知識庫文件」可看到第 1 版仍為已發布但非現行；歷史回答的出處卡仍指向當時版本。

## 3. 衝突與臨床問題轉督導（A2）

- 問：`住民跌倒沒有受傷，要在幾小時內完成異常事件紀錄？` → 「不同文件的規定不一致」→ 自動建案。
- 問：`住民發燒到 38.5 度要不要送醫？` → 規則攔截（涉及臨床判斷）→ 建案，不進 LLM。
- 問：`員工停車位怎麼申請？` → 知識庫無依據 → 建案。

## 4. 督導閉環（A7）

- 後台以 `sup_happy_a` 登入 →「待確認案件」→ 開啟案件 → 看去識別化問題、AI 檢索到但未採用的候選條文 → 「我來處理」→ 回覆 → 畫面顯示「回覆已保存；通知狀態：通知待送」→ 幾秒後重新整理變「LINE 已受理（不代表送達）」。
- 回 LIFF「我的案件」→ 看到督導回覆；可補充說明（會回到處理中）。

## 5. 分類快速回報（A7）

- LIFF「分類回報」→「家屬額外要求」→ 選常見問題 → 補充文字 → 「確認送交督導確認」→ 顯示案號與負責督導（示範督導 A）；改選「移位與行動協助」會到督導 B；「其他」進共用待處理區。

## 6. LINE 原生語音與重送（A4／A9）

- 後台「LINE 模擬器」→ 選 A1 → 傳文字「小照你好」→ 右側看到打招呼回覆與三個連結；傳文字問題 → 回覆含出處與快速回覆按鈕（送交督導確認／回答有誤／播放語音，可「模擬點擊」）。
- 上傳一段 wav／m4a → 「傳語音訊息」→ 先回「已收到語音」，worker 轉文字後推播「語音轉文字結果」＋「用這段提問」→ 模擬點擊 → 回答。
- 「重送上一則 webhook（isRedelivery）」→ 回應 `duplicate: 1`，不重複回覆、不重複建案。
- 「封鎖（unfollow）」後督導回覆 → 通知狀態「略過（已封鎖）」，回覆仍在系統內。

## 7. 談話錄音與角色確認（A5／A6；需有麥克風的瀏覽器）

- LIFF「錄音」→ 勾選同意 → 開始 → 說兩三句 → 停止 → 自動上傳 → 轉到確認頁。
- 看點：片段起訖時間、說話者預設「未辨識」；指定「說話者 1＝長輩」；勾選片段；填摘要；「確認送出」→ 只保存遮罩版；「用選取的片段向小照提問」或「分類回報並送交督導」。
- 無麥克風的瀏覽器：頁面顯示替代入口（LINE 語音訊息／外部瀏覽器）。

## 8. 免手模式（喚醒詞）

- 「問 AI」→「語音提問」→「免手模式」→ 說「小照你好，幫住民洗澡水溫要幾度」→ 提示音 → 錄音 → 停頓自動停止 → 轉文字 → 4 秒倒數自動送出 → 回答並自動播放語音。
- 提醒：喚醒詞辨識用瀏覽器 Web Speech API（第三方語音服務）；iOS／Android LINE 內建瀏覽器支援度未實測。

## 9. 治理指標與文件管理

- 後台「治理指標」：每項附分子／分母與定義；「知識庫文件」：上傳新版（缺生效日→「待補」不能發布）、預覽切塊、發布、停用。
- 「帳號與綁定」：為未綁定照服員產生綁定碼 → LIFF 以 A2 登入 → 綁定頁輸入 → 成功。

## 10. 建案失敗不假裝已轉交（A3）

- 需程式注入：`backend/app/services/cases.py` 的 `FAULT_INJECTION`（測試 `test_case_creation_failure` 已覆蓋）；畫面會顯示「⚠ 尚未送交督導」與「重試送交」。
