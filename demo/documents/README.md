# 合成展示文件

> **本資料夾所有文件皆為開發與展示用的合成範例，不是真實法規，也不是任何真實機構的規定。**
> 機構名稱「幸福園長照中心」「松柏居長照中心」均為虛構。條文內容、數字與時限是為了測試
> 版本差異、來源衝突、跨機構隔離與提示注入而設計，**不可作為照護實務依據**。
> 真實法規請由團隊從全國法規資料庫下載後，透過督導後台上傳、補齊生效日與來源再發布。
