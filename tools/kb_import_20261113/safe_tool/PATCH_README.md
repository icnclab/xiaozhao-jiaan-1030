1. 解壓縮本 ZIP 至獨立資料夾，不要直接解壓縮覆蓋正式專案。

3. 此腳本僅會更新 `run/seventh_candidate_work_20261113/` 的上述四個檔案，且會先比對原檔雜湊，確認吻合才複製；一旦目前版本有其他人修改過會直接拒絕，避免蓋掉新工作。
