# 需求對照表：長照 AI 照護小幫手（住宿式機構 MVP）

> 需求依據：本次開發提示語（2026-09-11）。
> 背景參考：`構想書_2026中華電信智慧創新應用大賽_接受修訂預覽.pdf`（僅作產品背景；其中統計、法規、服務能力與成效宣稱**未經本專案驗證**，不引用為事實）。

## 1. 產品邊界

| 做 | 不做（MVP） |
|---|---|
| 規範查詢（附出處）＋初步參考 | 醫療診斷、處方、用藥建議 |
| 依據不足／衝突／臨床判斷 → 轉督導 | 補助金額試算或承諾 |
| 經告知同意的談話錄音 → 轉錄草稿 → 照服員確認 | 背景持續監聽、鎖屏錄音、即時串流字幕 |
| 分類快速回報「送交督導確認」 | 法定通報、機構正式異常事件程序（介面不用「通報」字眼） |
| 督導後台：案件、文件版本、分類、回饋、指標 | 排班、人力即時調度、GraphRAG、完整工單平台 |

## 3. 與構想書不一致、本次改正的宣稱

| 構想書寫法 | 問題 | 本次處理 |
|---|---|---|
| 「機構資料不出境」「資料留在臺灣境內」 | 採 LINE 後，原生語音、聊天文字、播放音訊會經 LINE 平臺處理 | `docs/data-flow.md` 畫出第三方處理邊界；不沿用該宣稱 |
| 「複合信心分數」門檻 τ₁、τ₂ | 相似度不是正確機率 | 介面**不顯示**信心分數或正確率；門檻只作內部分流，並版本化 |
| 「LLM 評判員判定每句主張」 | LLM 評判不能證明正確 | 只作檢核訊號；引用存在性與文字支持度用決定性檢查；正確性需人工抽查 |
| 文字 P95 ≤ 5 秒、語音 P95 ≤ 10 秒 | 未驗證目標 | `docs/acceptance.md` 定義計時起訖與量測條件；結果照實記錄 |
| 語音「串流」至閘道 | MVP 不做即時串流 | 錄完或送出後自動上傳處理 |

## 4. 使用者與角色

| 角色 | 可做 | 資料範圍 |
|---|---|---|
| 照服員 caregiver | 提問、錄音、確認轉錄、分類回報、看自己的案件與回覆、回饋 | 自己的問答、紀錄、案件 |
| 督導 supervisor | 案件接收/分派/回覆/結案、文件上傳與發布、看指標 | 被授權機構的案件與文件 |
| 管理員 admin | 帳號、角色、分類模板、系統設定、綁定碼 | 被授權機構 |

MVP 一個帳號屬於一個機構；跨機構存取一律拒絕並寫稽核。
