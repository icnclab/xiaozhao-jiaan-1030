## 已核對的既有實作

- 資料表 categories：分類由 org_id 隔離，實際 ID 不在本檔臆造。category_templates 以 category_id 連接。
- 模板欄位為 id、category_id、text、sort_order、is_active；沒有草稿、來源、審核欄位。來源與待審狀態只保留在此審核檔及同名 JSON。
- 既有管理介面可讀取、建立及編輯，未找到模板批次匯入介面。GET /api/admin/categories 限督導／管理員並只回同機構；POST /api/admin/categories 與 PUT /api/admin/categories/{category_id} 限管理員。
- 管理介面儲存會將輸入題目設為 is_active=true；API 預設也為 true。不可拿草稿直接貼上儲存。
- PUT 是整組更新：漏傳的舊模板會被停用。因此不能僅用本檔3題覆蓋既有分類，也不能隨意 POST 新分類。
- 照服員 GET /api/categories 只回同機構啟用分類及其啟用模板；沒有獨立人工核准狀態。未審核模板不能靠系統自動審核阻擋，只能先保留在本機審核檔。
- 已知未修正邊界：create_case 對已開啟頁面的模板未再次檢查 is_active，因此不能宣稱任何停用模板都無法被舊頁面送出。本輪未修改程式或發布新模板。
