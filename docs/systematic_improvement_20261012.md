# 系統化改善驗證報告（2026-10-12）

本輪修改工作區程式並完成前端建置。後端驗證使用目前程式與正式知識庫的唯讀交易；未重啟運行中的後端，未新增問答、案件或改寫回饋審核資料。

## A. 問題群與修正

- 安全辨識：分別擴充呼吸、意識、跌倒／撞頭、突發身體異常、異常嘔吐／攝取不足、胸口不適、用藥選擇／換藥及環境安全的口語與短句。保留緊急規則優先順序，安全攔截先於資料查詢，不輸出疾病診斷。
- 否定語意：「沒有跌倒／還沒有跌倒」不再當成已發生跌倒；同一句的濕滑地板危險仍獨立判斷。
- BA16：用品、衛生紙、家人物品、距離／超距、補助品、代辦事項、購物後清理歸位、記帳、藥品／處方藥與代購代領代送分成欄位意圖。排除衛生紙使用方式、會計／薪資記帳等反例。
- 資料查詢：修正正式文件換行造成的關鍵詞漏比對；已通過資料門檻的表格欄位優先於不相干手冊。不調低全域門檻。
- 回答：對正式 BA16 表格，以同版本、同表格範圍的實際段落摘錄所問欄位，仍經既有引用、內容支持及輸出安全驗證；缺少標題、欄位、同版本來源或含可疑指令時不套用。避免模型在衛生紙、整理歸位等同義問法下產生不同結論。
- 呈現：精簡藥品回答為服務範圍、本人所需、用藥安全提醒及引用；不附帶公里、家人費用、購物清單與整理流程。詢問整理或記帳時只呈現所問流程。保留與所問事項相關的限制、否定與例外，合併等義及完全重複句子。公開引用只保存實際呈現答案使用的段落。

所有原有資料門檻保持不變：min_top_coverage=0.18、min_combined=0.24、min_evidence_score=0.16、min_support=0.45、min_gate_vector=0.52、min_gate_body_topic=0.50、min_gate_title_topic=0.80、min_gate_rule_topic=0.80。

## B. 新增測試

新增 **104 種不同自然語言測試問法**，不包含原始 14 題：48 題安全正例（八群各六題）、20 題安全反例、27 題 BA16 同義／短句、3 題否定跌倒但仍有環境風險、6 題不相關意圖反例。

另測試正式段落的資料門檻、缺標題／跨版本／缺欄位／可疑指令、例外訊息遮蔽及各角色顯示。自然語言問法數與測試執行項數分開計算。

## C. 前台用語與錯誤處理

照服員、督導及管理員共用白話轉換：

| 內部用語 | 公開顯示 |
|---|---|
| risk_fall_head_impact | 跌倒或頭部碰撞風險 |
| risk_environmental_safety | 環境安全風險 |
| respiratory_abnormality | 呼吸異常 |
| consciousness_abnormality | 意識狀態異常 |
| sudden_neurologic_abnormality | 突發身體異常 |
| abnormal_vomiting_or_intake | 異常嘔吐或攝取不足 |
| medication_selection | 用藥安全 |
| no_evidence | 找不到足夠資料 |
| clarification | 需要補充說明 |
| RISK_RULES / CLARIFICATION_RULES | 安全規則／澄清規則 |
| Gold | 標準案例 |
| regression / proxy | 測試結果／參考結果 |
| retrieval / evidence admission | 參考依據／參考依據確認 |
| verified / rejected / pending_review | 已驗證／已駁回／待審核 |

回答卡、案件列表／詳情、統計、回饋與審核摘要均轉換。管理員也不顯示原始技術紀錄或 JSON；適用規則以中文選項顯示，內部選項值不變。未知內部代碼顯示「需要確認」。歷史答案中的風險代碼亦轉成中文。

- 有安全風險：中文安全提醒、通知督導；緊急風險保留緊急救護提醒。
- 缺少具體問題：請使用者補充。
- 找不到規範：目前找不到足夠的規範依據，請送交督導確認。
- 系統例外：系統目前無法完成回答，請稍後再試或送交督導確認。
- API 錯誤訊息與前台錯誤顯示均不回傳／顯示 traceback、Python／資料庫例外及內部規則代碼；中文輸入提示保留。
